# katalog-coffee-shop
Sistem Katalog Coffee Shop
untuk Memudahkan Pilihan Menu adalah proyek perangkat lunak yang dirancang untuk membantu pelanggan melihat, mencari, dan memilih menu di sebuah coffee shop secara digital tanpa bergantung pada menu cetak. Melalui sistem ini, pelanggan dapat melihat daftar menu lengkap dengan gambar, harga, ukuran, dan informasi alergen, mencari menu berdasarkan kata kunci, menyaring menu berdasarkan kategori, harga, atau suhu, serta mengetahui menu terlaris, promo yang sedang berlaku, dan status ketersediaan menu. Di sisi lain, admin coffee shop dapat mengelola data menu, kategori, harga, varian ukuran, promo, dan ketersediaan menu dengan lebih praktis, sehingga informasi yang diterima pelanggan selalu akurat dan mudah diperbarui. Proyek ini saat ini berada pada tahap perancangan sistem yang meliputi use case diagram, activity diagram, sequence diagram, dan class diagram, serta dikerjakan secara berkelompok dengan memanfaatkan GitHub sebagai sarana kolaborasi dan pengelolaan versi.
